## GitHub Integration

Connect your documentation spaces directly to GitHub repositories for version-controlled documentation.

<Tabs>
  <Tab title="Repository Sync" icon="git-branch">
    Automatically sync documentation changes with your GitHub repository.

    <Steps>
      <Step title="Connect Repository" icon="link">
        Link your GitHub repository to a documentation space.
      </Step>
      <Step title="Configure Sync" icon="settings">
        Set up automatic syncing for pushes and pull requests.
      </Step>
      <Step title="Monitor Changes" icon="eye">
        Track documentation changes alongside code changes.
      </Step>
    </Steps>

    <CodeGroup tabs="YAML,JSON">
      ```yaml
      # .github/workflows/docs-sync.yml
      name: Sync Documentation
      on:
        push:
          paths:
            - 'docs/**'
      jobs:
        sync:
          runs-on: ubuntu-latest
          steps:
            - uses: dayslla-lays/sync-action@v1
              with:
                api-key: ${{ secrets.DAYSLLA_API_KEY }}
                space-id: ${{ secrets.SPACE_ID }}
      ```
      ```json
      {
        "repository": "your-org/your-repo",
        "sync_path": "docs/",
        "auto_commit": true,
        "branch": "main"
      }
      ```
    </CodeGroup>
  </Tab>
  <Tab title="Pull Request Reviews" icon="git-pull-request">
    Include documentation reviews in your pull request process.

    <Expandable title="Review Process" default-open="false">
      When a pull request is created, Dayslla Lays can automatically check for updated documentation and suggest reviews.
    </Expandable>
  </Tab>
</Tabs>

## Slack Integration

Keep your team informed about documentation changes through Slack notifications.

<Request tabs="cURL" show-lines="true">
  ```bash
  curl -X POST https://api.dayslla-lays.com/v1/integrations/slack \
       -H "Authorization: Bearer YOUR_API_KEY" \
       -H "Content-Type: application/json" \
       -d '{
         "webhook_url": "https://hooks.slack.com/services/...",
         "channel": "#docs-updates",
         "events": ["doc.created", "doc.updated"]
       }'
  ```
</Request>

<Response tabs="Success" show-lines="false">
  ```json
  {
    "integration_id": "slack_123",
    "status": "active",
    "channel": "#docs-updates"
  }
  ```
</Response>

## CI/CD Integration

Automate documentation deployment as part of your CI/CD pipelines.

<ExpandableGroup>
  <Expandable title="GitHub Actions" default-open="true">
    Use our GitHub Action to deploy documentation changes automatically.

    <CodeGroup tabs="YAML">
      ```yaml
      - name: Deploy Documentation
        uses: dayslla-lays/deploy-action@v1
        with:
          api-key: ${{ secrets.DAYSLLA_API_KEY }}
          space-id: ${{ secrets.SPACE_ID }}
          source-path: ./docs
      ```
